# ORPHIC → OBS ports (2026-10-13)

Source: [ORPHIC](https://github.com/adityarajashekaran/orphic), commit `47a8d5d`, © 2026 Aditya Rajashekaran. Derived files carry `SPDX-License-Identifier: AGPL-3.0-or-later` and attribution; treat redistribution of this mixed-license collection as a separate licensing review, not as automatically covered by ShaderFilter's repository license.

These standalone `.shader` files target the **standard ShaderFilter wrapper**, file-backed mode, with user controls and OBS `audio_peak` / `audio_magnitude` uniforms:

| File | Transfer | Differences from ORPHIC |
|---|---|---|
| `orphic_chladni.shader` | Three standing-wave eigenmodes, shimmering domain warp, glowing nodes | Manually selected mode families; peak/RMS instead of FFT-band weights and beat-triggered mode retuning |
| `orphic_hyperdrive.shader` | Polar demoscene tunnel, spokes, derivative fade, star streaks, chromatic depth | Periodic rather than event-queued beat rings; stable clock rather than accumulated music-driven travel |
| `orphic_escher_gate.shader` | Poincaré disk tiling through triangle-group folds | Manual {p,q} selection; peak/RMS rather than spectral texture and 16-beat retiling |

**How to use:** Add a **Shaderfilter Source** or attach a **Shaderfilter Filter** to an existing OBS source. Select the `.shader` file, **leave Full Vertex Shader (.effect) off**, use **Reload Effect**, and choose an audio source in the filter settings if needed. `Mix With Source = 1` uses the generated scene; `0` leaves the input source unchanged. For full-screen visuals, the standalone source is preferable.

**Verified:** All three compiled with native libobs 32.0.1 OpenGL effect compilation, using the *actual standard wrapper text from this checkout*, and rendered nonempty frames through Mesa llvmpipe at 256×144. At the time of those historical checks, installed copies under `~/.config/obs-studio/plugins/obs-shaderfilter/data/examples/` were byte-identical when copied. The fork examples now live under `data/examples/myrqyry/`; this relocation does not rerun those historical audio or standalone-source checks. No real microphone/audio-device routing, shader UI interaction, Windows/macOS backend, full-resolution performance, or visual parity test was completed. An isolated direct **Shaderfilter Source** module harness returned an empty frame and the default 1920×1080 dimensions; this may be missing OBS scheduler/tick setup in the harness, but **that path has not passed runtime verification**. Do not conflate the two boundaries.

**Stateful follow-up:** `~/MQR/hyperShaderFX/data/shaders/root/orphic_turing_bloom.effect` demonstrates genuine Gray-Scott feedback with a reversible chemical-state encoding in RGB. This is not a full port of ORPHIC's multi-target simulation. Direct libobs GL verification observed different image checksums at frames 1, 24 and 90 at 160×96; runtime integration and long-term stability remain separate tests. HyperShaderFX already has a distinct native `chladni_resonance.effect`, so do not duplicate it.

For the original Physarum, fluids, Lenia, star river, or swarm scenes, a full port needs independent simulation render targets, separate update and display passes, and for particles a deposition/draw path. HyperShaderFX's `iPreviousFrame` alone is not that pipeline.

## Additional ports (2026-10-13)

- `orphic_obsidian_sanctum.shader` — an additional ShaderFilter one-pass Mandelbox raymarcher based on ORPHIC `js/scene-obsidian-sanctum.js`. Controls bound the default raymarch to 40 steps and 8 fractal iterations rather than ORPHIC's 96 x 11 full raymarch plus adaptive-resolution upscaling. Traces original box/sphere folds, orbit-trap material and normal/fresnel lighting; replaces spectral glow with audio peak/RMS and omits separate AA/chromatic postpass. **Native libobs 32.0.1 OpenGL (llvmpipe) compiled and rendered a nonempty 256×144 frame, checksum 15082048**. Significant frame cost at full OBS resolution is not evaluated. Do not claim full-res performance.
- `~/MQR/hyperShaderFX/data/shaders/root/orphic_aurora_veil.effect` — an additional HyperShaderFX native audio-reactive aurora shader based on ORPHIC `js/scene-aurora-veil.js`. Keeps procedural starfield, two domain-warped curtain layers, palette, horizon and flow. Uses **eight independent HyperShaderFX FFT band uniforms** interpolated across the sky, rather than ORPHIC's peak-decay FFT spectrogram history; live audio capture still needs an OBS integration check. Native libobs 32.0.1 OpenGL render test at 256×144 **passed** with opaque and colored output. Synthetic audio profiles gave distinct pixel checksums: silence `9653386`, bass `11699619`, treble `11895829`. This establishes shader responsiveness to externally supplied uniform values, **not** the entire real audio-device pipeline.

The additional source and installed OBS library copies are byte-compared at install. No system OBS binaries or plugin code are altered.

## Event Horizon, Stellar Nursery, Spectral Bloom (2026-10-13)

These were derived from ORPHIC at commit `47a8d5d`. Keep their per-file AGPL-3.0-or-later notices and source attribution; the compatibility of mixed-license distribution must be assessed before redistributing the complete repositories.

| Port | Target | What was retained | What changed |
|---|---|---|---|
| `orphic_event_horizon.shader` | Standard ShaderFilter wrapper | Photon geodesic integration with radial gravitational acceleration, black-hole capture/escape, accretion disk intersection, Doppler-inspired emission, photon-sphere halo, procedural sky | Peak/RMS in place of the FFT-driven sky/chroma and beat analysis; no adaptive lower-resolution framebuffer or postpass; user-bounded geodesic steps default to 64 versus original 240 |
| `~/MQR/hyperShaderFX/data/shaders/root/orphic_stellar_nursery.effect` | HyperShaderFX full OBS effect | Gyroid-based volume density, per-step absorption/emission, radial illumination and central stellar flare | Eight audio bands in place of the log-frequency spectrum texture; periodic traveling shock in place of CPU beat-driven ring queue; 32 volume steps by default versus original 40; no adaptive render-scale/postpass |
| `~/MQR/hyperShaderFX/data/shaders/root/orphic_spectral_bloom.effect` | HyperShaderFX full OBS effect, previous-frame feedback | Twelve-lobed flower, radial frequency rings, rotating/zooming persistence and time-based shimmer | Eight frequency bands mapped over twelve geometric sectors are **not** ORPHIC's twelve pitch-class chroma measurements; a single composited feedback pass replaces its three-pass scene/accumulation/show architecture. Not a chord visualizer |

**Native libobs 32.0.1 OpenGL receipts:** `orphic_event_horizon.shader` compiled with the exact local ShaderFilter standard-wrapper text and rendered an opaque, nonempty 256×144 frame (checksum `17457639`). `orphic_stellar_nursery.effect` compiled and rendered opaque, nonempty 256×144 frames with distinct synthetic audio uniform profiles: silent `9873465`, bass `14475450`, treble `10256965`. `orphic_spectral_bloom.effect` compiled and rendered 160×96 frames with a constant time and constant synthetic audio value: with feedback decay `0.78`, its pixel checksums changed `4290629` → `4671408` → `4984898` (frames 1/4/12); with feedback disabled, all remained `4290629`. This demonstrates real GPU feedback, not fake animation.

All tests used OBS/libobs's OpenGL effect compiler and Mesa llvmpipe. They do **not** demonstrate that the installed ShaderFilter Source/Filter or HyperShaderFX source UI successfully loads and renders these files, that an actual microphone drives audio, visual parity, or full-res/streaming framerate. The geodesic march and volumetric march are expensive; use small sources and adjust quality controls on the actual target GPU before live streaming. In both HyperShaderFX effects, `image` blending expects a valid source frame in filter mode; standalone source mode should use mix = 1 and doesn't have an external camera input.
